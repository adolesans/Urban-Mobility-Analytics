> **Strategic Business Intelligence dashboard analyzing urban mobility patterns and seasonal demand forecasting for bike-sharing systems.**

## 📌 Project Overview
**Urban Mobility Analytics** is a data science project aimed at uncovering deep insights from bike-sharing operational data. By analyzing historical rental patterns, this project identifies key drivers behind user behavior, seasonal trends, and environmental impacts on urban transportation.

The final output is an **interactive Streamlit dashboard** that allows stakeholders to explore data dynamically and make informed decisions regarding fleet distribution and marketing campaigns.

## 🚀 Key Features
* **Interactive Dashboard**: Deployed via Streamlit, featuring real-time data filtering and dynamic visualizations.
* **Comprehensive EDA**: Deep dive into seasonal trends, holiday impacts, and hourly rental distributions.
* **Customer Segmentation**: Comparative analysis between Casual riders and Registered members to identify unique behavior markers.
* **Weather Impact Correlation**: Statistical analysis of how temperature, humidity, and weather conditions affect rental frequency.

## 🛠️ Tech Stack
* **Language**: Python
* **Analysis**: Pandas, NumPy, Scipy
* **Visualization**: Matplotlib, Seaborn, Plotly
* **Deployment**: Streamlit

## 📊 Key Insights (Sample)
* **Peak Hours**: Rentals peak during commute hours (08:00 and 17:00) on weekdays, suggesting a strong utility for professional commuters.
* **Weather Sensitivity**: Rental volume shows a significant positive correlation with temperature, peaking during clear/partly cloudy conditions.
* **User Behavior**: Registered users dominate weekday rentals, while Casual users show a spike during weekends and holidays.
